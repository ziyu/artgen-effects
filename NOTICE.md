# Source and attribution

These six algorithms were originally developed for [Artgen](https://artgen.net).
The initial extraction preserves algorithm version `1` from `ziyu/artgen`
commit `f154d62ea0fef4b8c8940c33df37ccb9497be997`.

This repository contains the independently packaged image algorithms, shared
pixel helpers, API validation, tests, and documentation. It does not distribute
the Artgen application or its upstream application template.

The ASCII bitmap glyphs are original, embedded shapes. The algorithms have no
third-party runtime dependencies. Development tools retain their own licenses.
No third-party photographs, fonts, or model weights are included.
